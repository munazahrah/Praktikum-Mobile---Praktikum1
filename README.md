#Praktikum1

Project Modul 1 - Setup & Aplikasi Pertama

📖 Deskripsi

Project ini adalah tugas pertama dari mata kuliah Mobile Programming. Tujuannya adalah untuk memastikan seluruh lingkungan pengembangan (environment) Flutter dan Android Studio telah terpasang dengan benar di komputer Anda.

Tugas ini memvalidasi instalasi dengan cara memodifikasi dan menjalankan aplikasi default Flutter.

🎯 Tujuan Utama Project

Validasi Instalasi: Membuktikan bahwa Flutter SDK dan Android Studio (termasuk Android SDK) telah terpasang dan terkonfigurasi dengan benar.

Modifikasi Sederhana: Melakukan perubahan kecil pada kode default untuk membiasakan diri dengan struktur file main.dart.

Pengujian Perangkat: Memastikan aplikasi dapat dijalankan di Emulator (AVD) dan di Perangkat Android Fisik (HP).

✅ Daftar Tugas (To-Do List)

Berikut adalah hal-hal yang harus Anda lakukan:

Pastikan Instalasi Berhasil:

[ ] Jalankan flutter doctor di terminal Anda. Pastikan tidak ada error kritis (tanda [X]).

Buat Project Baru:

[ ] Buat "New Flutter Project" melalui Android Studio.

Modifikasi Kode (lib/main.dart):

[ ] Buka file lib/main.dart.

[ ] Cari bagian AppBar dan ubah teks title-nya menjadi: "Program Pertamaku".

[ ] Cari bagian Text di tengah layar (biasanya "Hello World" atau "You have pushed the button this many times:") dan ganti teks tersebut menjadi Nama Lengkap Anda.

Jalankan & Uji Coba:

[ ] Jalankan aplikasi di Emulator (Android Virtual Device) yang sudah Anda buat.

[ ] Jalankan aplikasi di HP Android Fisik Anda (pastikan USB Debugging sudah aktif).

Analisis Sederhana:

[ ] Amati dan bandingkan waktu yang dibutuhkan aplikasi untuk startup (dari run hingga tampil) antara Emulator dan HP Fisik. Catat mana yang lebih cepat.
